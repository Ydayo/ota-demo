# ADR-0014: 他のユーザーのリソースへのアクセスには 404 を返す

- 日付: 2026-09-27

## 背景

認可ポリシー `owner`(本人のリソースのみ、ADR-0010)のルートに、ログイン済みの別のユーザーがアクセスした場合の応答を決める必要がある。403(権限なし)を返すと、そのリソースが存在することを相手に知らせてしまう。予約番号などを総当たりで試されると、存在する予約番号を特定される。

## 決定

- 他のユーザーのリソースへのアクセスには、リソースが存在しない場合と同じ 404 を返す。応答の本文も同じにする。
- 未ログインの場合は 401 を返す(存在の有無は判定しない)。
- OpenAPI の定義上も、`owner` のルートの拒否レスポンスは 401 と 404 のみとする。

## 検討した選択肢

- 403 を返す: 利用者に理由が伝わりやすいが、リソースの存在が漏れるため不採用。

## 結果

- リソースの存在を、所有者以外に知られない。
- 認可の自動検査(ADR-0010)では、「別のユーザーのリソースへのアクセス」が 404 になることを確認する。
