# ADR-0007: GitHub Actions の CI を最終ゲートとし、AI は専用アカウントで PR を作る

- ステータス: 提案中
- 日付: 2026-09-27

## 背景

ローカルの Git hooks や Claude Code の hooks は、AI が迂回できる。最終的な品質判定は、AI が迂回できない場所で行う必要がある。また、AI が人間と同じ GitHub アカウントで PR を作ると、PR の作成者とコードオーナーが同一になり、CODEOWNERS によるレビュー必須が機能しない。

## 決定

- リポジトリは GitHub の公開リポジトリとする(無料プランでブランチ保護を使うため。ポートフォリオとしての公開も兼ねる)。
- main ブランチを保護する。
  - PR 経由でのみマージできる
  - コードオーナーのレビューを必須とする
  - CI の集約ジョブ `ci-ok` の通過を必須とする
  - 管理者にも適用する
- AI は専用のマシンアカウント(Write 権限、Admin 権限なし)で push し、PR を作る。トークンはこのリポジトリに限定した fine-grained PAT とする。
- 人間の GitHub 認証情報を AI が使わないよう、リポジトリ単位で bot の認証情報を設定し、`.claude/settings.json` の deny で認証の切り替えやキーチェーンの読み出しを禁止する。

## 検討した選択肢

- ローカルの hooks を最終ゲートにする: 迂回できるため不採用。
- GitHub App で PR を作る: 無料で使えるが、トークンの発行(有効期限1時間)の仕組みが必要になり、個人開発には過剰なため不採用。
- 非公開リポジトリ: 無料プランではブランチ保護が効かないため不採用。

## 結果

- CI を通過し、人間が承認しない限り、main に変更は入らない。
- CODEOWNERS による保護対象(ADR-0006)の人間レビューが実効性を持つ。
