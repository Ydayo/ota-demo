# ADR-0014: ADR のステータス欄を廃止する

- 日付: 2026-09-27
- 関連: ADR-0001 のステータスに関する決定を置き換える

## 背景

ADR-0001 では、ADR に「提案中」「承認済み」などのステータス欄を設けた。しかし、ADR は必ず PR で追加され、ルールセット(ADR-0007)により人間が承認した PR しかマージされない。そのため main にある ADR はすべて承認済みであり、ステータス欄は情報を持たない。さらに、承認後にステータスを書き換えると push によって承認が取り消され、人間が2回承認する必要が生じていた。

## 決定

- ADR にステータス欄を設けない。main にある ADR は、すべて有効な決定である。
- レビュー中かどうか、承認されたかどうかは PR が表す。承認されなかった ADR は main に入らない。
- 判断を変える場合は新しい ADR を作り、「関連」欄に置き換える ADR と範囲(全部 / 一部)を書く。
- 置き換えられた ADR には、タイトルの直後に「> ADR-NNNN で置き換え(範囲)」の注記を1行だけ加える。これが、main にある ADR に許される唯一の変更である。

## 検討した選択肢

- PR の作成時点から「承認済み(PR #N)」と書く: 承認前の PR に事実と異なる記載が入るうえ、ステータス欄が情報を持たない点は変わらないため不採用。
- 承認後にステータスを書き換える(ADR-0001 のまま): 人間の承認が2回必要になるため不採用。

## 結果

- 人間の承認は1回で済む。
- ADR の有効性は「main にあるか」と「置き換えの注記があるか」で判断できる。
